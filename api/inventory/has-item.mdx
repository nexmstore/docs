Check whether a player has a specific item. This is a predicate method: it returns `false` when the item is absent, and returns an error only when the check itself fails.

<Note>
  `false` means the item is not present. An error (`err ~= nil`) means the check could not be completed. Do not treat `false` as an error.
</Note>
