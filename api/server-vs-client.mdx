NEXM Core exposes some APIs on both sides and others only on the server. Use this page to decide where each call belongs.

## Server-side APIs

These modules and operations are available only on the server:

- Player (full module)
- Jobs
- Money
- Inventory mutations
- Permissions
- Callback (registration and handling)
- Events (server emitters)
- Locale (server context)
- Log / Audit
- Validate
- RateLimit
- Resources
- Services
- Features
- Integrations
- Components
- Version
- Database
- Migrations

## Client-side safe APIs

These modules are safe to use from the client:

- Player (read-only queries)
- Callback (triggering)
- Notify
- Locale
- Events (client emitters)
- Validate
- Version

<Warning>
  Money, inventory mutations, and permissions must be handled server-side. Never perform these operations from the client. See [Security Model](/concepts/security-model).
</Warning>
